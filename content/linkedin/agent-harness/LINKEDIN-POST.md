## Post copy — carousel version (primary)

Nine in ten AI agents never leave the pilot.

Not because the model isn't good enough. Deloitte has 38% of organizations piloting agents and 11% running one in production — and when leaders are asked what stopped them, they name evaluation gaps, governance friction and reliability.

Every one of those is a harness problem. And every harness problem traces back to an input nobody wrote down before the build started.

There are four of them, and if you've ever run a strategy engagement you've already written all four:

→ The brief becomes the system prompt and the permission boundary
→ The journey map becomes the tool allowlist and the escalation gate
→ The measurement plan becomes the eval harness
→ The segmentation becomes the retrieval strategy

Here's the part that should end the "which model should we use" conversation: Microsoft held the model constant and changed only how the system was allowed to look for evidence. BRIGHT recall@1 went from 27.8% to 49.6%. Same model. Different harness.

The corpus is the variable you actually control.

A suspension bridge is built in a fixed order. Deck. Towers. Main cable. Suspenders. Then the load.

→ The brief → the system prompt and permission boundary
→ The journey map → the tool allowlist and escalation gate
→ The measurement plan → the eval harness
→ The segmentation → the retrieval strategy
