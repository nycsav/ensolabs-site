01The problem, measured

We onboarded Enso Partners LLC onto Partner Plus and instrumented the friction. Every item below cost real hours.

No API. partnerportal.ibm.com/s/ is Salesforce Experience Cloud — built for humans to click. No endpoints for tier, benefits or credits.
Benefits are invisible until you hunt. Technology Zone is free at Registered tier — most partners never find it and wait weeks on Cloud Credits instead.
Errors mislead. A 401 Invalid API key looked like a billing problem. It was a stale key. Credits were never involved.
The default path asks for your credit card. The partner path is one unlabelled link away: "Register with a code".
Sponsor tickets are invisible. IBM-internal tickets never copy the partner. There is nothing in your inbox to find.

04Install

One command. Works in any MCP host.

# Register the harness with Claude Code
claude mcp add enso-research --scope user \
  --env PERPLEXITY_API_KEY="your-key" \
  -- python3 /path/to/enso-research-mcp/server.py

# Then, in any MCP host:
"What's unlocked at my Partner Plus tier?"
"My IBM API key returns 401 but I have credits — why?"
"Where can I build watsonx without Cloud Credits?"

Read-only by design. The harness searches, compares and explains. It never sends, posts, purchases, or accepts terms — those stay human.
